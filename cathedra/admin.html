Configuration Firebase
  1. Dans Firebase, crée une application Web et renseigne sa configuration dans firebase-config.js.
  2. Active Authentication avec e-mail et mot de passe, Firestore et Storage.
  3. Publie les règles fournies dans firestore.rules et storage.rules depuis la console Firebase.
  4. Crée ton utilisateur dans Authentication, puis dans Firestore crée le document admins/UID en remplaçant UID par son identifiant Authentication.
  5. Connecte-toi ici et ajoute les produits. Les changements sont enregistrés dans Firebase.
