## 10 carrousels (5 cartes chacun)

1. **Manifeste :** « Porter l'entre-deux » / silhouettes simples / signe discret / douceur et intensité / Vesper Vale.
2. **Scorpio Season :** glyphe linéaire / constellation / phrase courte / placements cœur-manche-nuque / capsule en préparation.
3. **La pièce en détail :** face / dos / macro réelle / étiquette réelle / composition validée.
4. **Composer un duo :** 39 € / ajouter un deuxième / total 50 € / port en sus / choix de deux coloris.
5. **Guide des tailles :** tableau mesuré / coupe portée / modèle + taille / comparer à un vêtement / conseil d'entretenir.
6. **De l'esquisse au prototype :** dessin / placement papier / premier échantillon réel / correction / produit approuvé; ne jamais inventer étapes non réalisées.
7. **Palette :** encre / craie / griotte / mousse / échantillons textile réels; indiquer si écran seulement.
8. **Broderie rapprochée :** macro / envers / échelle sur corps / test lavage / détail confirmé.
9. **FAQ d'achat :** prix / tailles / livraison / retours / contact; ne publier que les modalités renseignées.
10. **Le journal du drop :** intention / 4 modèles / prix / date confirmée / lien d'achat; publier seulement une fois prêt.
